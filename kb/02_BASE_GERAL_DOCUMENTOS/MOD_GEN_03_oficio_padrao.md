# OFICIO — ESQUELETO UNIVERSAL

```
Sao Luis, {DATA_OFICIO}.

A Sua Senhoria o(a) Senhor(a)
{NOME_DESTINATARIO}
{CARGO_DESTINATARIO}

Assunto: {ASSUNTO}.

{VOCATIVO},

Considerando {PECA_INTERNA_DE_REFERENCIA}, {VERBO_DE_AUTORIZACAO_OU_SOLICITACAO}
{OBJETO}, conforme detalhamento que segue:

{TABELA_DETALHAMENTO}

{CLAUSULA_ACESSORIA_OPCIONAL}

Atenciosamente,

{ASSINANTE}
{CARGO_ASSINANTE}
```

## REGRA DE VINCULACAO
Todo OFICIO deve citar a peca interna que o fundamenta (`MANIF-CAEDNC` ou `INFORMA-CAEDNC`)
pelo numero. Se o numero nao foi informado, gravar `[DADO FALTANTE: numero da
manifestacao/informa]` — jamais numerar por conta propria.
